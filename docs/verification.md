## 주행 변화

- 기본 최고속도 18→26m/s, 표시 약94km/h. 카트는 출발 후0.8초 안에 기본 최고속도의90% 이상에 도달한다.
- 카트는 드리프트 게이지32%/75%에서 일반/슈퍼 부스트. 즉시 속도 +5/+8m/s, 제한 속도 +9/+14m/s, 지속1.1/1.7초. 부스트 종료 시 한 프레임에 정상 속도로 잘리지 않고 감속한다. 반복 발동도 제한 속도를 넘지 않는다.
- 다운힐은 조향과 이동 방향이 더 느리게 따라오는 관성, 브레이크 진입 슬라이드, Space 미끄러짐을 제공한다. 해제 부스트는 없고 완료한 드리프트가 품질 점수에 반영된다. 충돌한 순간에 끝난 슬라이드는 성공으로 세지 않는다.
- 정지 또는 직진으로만 드리프트 점수를 만들지 못하며 제동·충돌·복귀가 상태를 정리한다. 기존 역주행·복귀·구간 반복의 중복 생산 방지는 유지된다.

| 코스 | 길이 | 카트 실제 실행 | 다운힐 실제 실행 |
|---|---|---|---|
| 1번 · 슈가웨이 | 560.81m | 22.34초 | 22.40초 |
| 2번 · 클라우드런 | 668.62m | 26.46초 | 26.52초 |

위 실행 기록은 기본 속도에서 자동 시험 운전자가 낸 수치이고 모두 충돌0회다. 첫 레시피 기록23.34초에는 정지 검사1초가 포함된다. 순수 시뮬레이션에서도 두 스타일이 본선과 지름길을 실제로 완주한다. 지름길 단축 거리는 약13.0/16.6m다.

다운힐 시험 운전자의 좌우 경로 변화가 첫 실행에서 북쪽 코너 벽을 스쳤다. 같은 위치·입력을 순수 시뮬레이션으로 재현했고, 앞을 보는 거리를14→16m로 바꾸면 0.8m의 좌우 변화를 유지하며 두 맵 모두 충돌 없이 완료함을 확인했다. 생산 코드와 충돌 검사 조건은 변경하지 않았다. 증거는 `Logs/runtime-path-probe.txt`다.

## 실제 게임에서 확인한 흐름

- 카트의 세 맛×두 크기 6개 레시피, 다운힐의 두 맵 완주와 정확한 크기·맛.
- 가게에서 스타일 선택 → 해당 물리와 카트/쿠페 모델 적용 → 주행 중 스타일 변경 금지 → 복귀 후 다시 선택.
- 중량이 먼저 차도 주행 계속, 한 바퀴 완주해야 제품·보상 지급. 포기·제한 시간 초과는 제품과 보상 없음. 중복 완료와 중복 전달 방지.
- 카트 슈퍼 부스트 발동과 화면 시야 확대·속도선, 다운힐 슬라이드 완료와 품질 횟수 전달. 일시정지 시 카메라·속도선·주행 소리 중단, 음소거 시 바람·엔진·부스트 소리 중단.
- 주문 자동 설정, 직접 건네기와 팁, 잘못된 재고 보호, 저장, 진열대6→9→12, 가득 찬 재고 출발 제한과 선택 재고 삭제.
- 기존 V1/V2→V3 저장 이전, 고객 대기 비율·코인·재고·업그레이드 보존, 품질 검증.

## 화면·Blender·배포

카트·다운힐·슈퍼 부스트·가게 화면을 직접 확인했다. 1600×900,1280×720,1280×960,1920×820에서 버튼 범위와 텍스트 넘침을 검사한다. 출발 안내가 차를 가리지 않도록 상단으로 옮겼다. 최종 캡처는 `docs/screenshots/feel-*.png`다.

Blender로 만든 스포츠쿠페는 50개 메시,8,896삼각형,1.552×3.100×1.050m다. 원본과 다시 임포트한 FBX의 좌표·면적·닫힌 메시·외향 법선·재질·크기·휠 회전축·앞 방향을 검증했다. 기존 에셋까지 총18종을 사용한다. 코스 주변 소품은 차가 다니는 위치와 렌더러 경계가 겹치지 않는지 Unity에서 확인했다.

두 모드는 현재 같은 평면 코스에서 조작감을 비교한다. 다운힐 전용 산길·경사 지형이나 경쟁 AI는 이번 변경에 포함되지 않는다. 주행 스타일은 이번 실행 중 유지되며 저장 형식V3는 그대로다.

배포 경로: `Builds/DrivingFeel/CottonCircuit.exe`. 현재 열려 있던 예전 `Builds/Windows/CottonCircuit.exe`는 종료하지 않았다. 저장 경로가 같으므로 이전 게임을 닫은 뒤 새 실행 파일을 사용한다. 최종 UI 조정 후 Windows 실행 검증188개가 다시 통과했으며, 차량을 가리지 않는 출발 안내 위치를 최종 캡처에서 확인했다.

최종 Release: 종료 코드0, COTTON_RELEASE_SUCCESS 101915881, build-info.json의 Release 구성을 확인했다. 자동 플레이 코드는 배포 빌드에서 제외된다.
