# 주행 리듬 개선 설계

2026-09-21, baseline 2f6ad73. 사용자의 긴 맵/밋밋한 주행 피드백을 기존 게임의 수정 요청으로 반영한다. 현재 진행 중인 제작과 경영의 구조를 유지한다.

## 목표

기본 차량으로 1번 맵 약20~25초, 2번 맵 약25~30초. 긴 완만한 구간을 압축하고 코너 진입→드리프트 충전→탈출 부스트가 한 판에 여러 번 이어진다. 수동 조향을 유지하며 사람의 재미 판단은 자동 검증으로 확정하지 않는다.

## 선택

코스 축소만 하면 속도감과 드리프트 보상은 그대로 남는다. 최고 속도만 올리면 기존 디지털 조향이 더 어렵다. 코스 길이, 가속/조향, 부스트 피드백을 함께 조정하는 카트 방향으로 수정한다. 선호도 질문은 선택 사항이며 답이 없으면 이 방향으로 진행한다.

## 변경

- 코스1 520~620m, 코스2 640~750m, 기존 두 형상을 바탕으로 코너 간 간격을 압축한다. 지름길과 도로 폭은 유지하고 중앙 기계와 맵 경계의 여백을 줄인다.
- 기본 속도18→26m/s, 카트는 가속 후0.8초 안에 기준 속도의90% 이상. 업그레이드 증분2.5 유지.
- 조향 입력을 짧게 완충하고 고속에서 회전율을 줄여 키보드 오버슈트를 완화한다. 드리프트 중 미끄러짐은 유지하되 복귀 반응을 높인다.
- 드리프트 게이지0.32/0.75에서2단계 부스트. 낮은 단계1.1초, 높은 단계1.7초를 기준으로 튜닝. 발동 순간 속도 증가, 종료 시 부드러운 감속, 브레이크/충돌/복귀 시 취소. 정지/직진 Space만으로 충전하지 않는다.
- 낮고 가까운 추적 카메라, 부스트 시 시야 확대/작은 뒤로 당김, 가장자리 속도선과 부스트 소리로 피드백. 과한 흔들림은 넣지 않는다. Blender에서 만든 기존 터널/표지/수정/나무를 가까운 주행 구간에 재배치한다.
- 맵별 크기60/120g, 고른 맛 고정, 한 바퀴 완주, 직접 판매, 저장V3 유지. 기록 기준만24/30초로 맞춘다. 타임아웃과 고객 대기시간은 유지한다.

## 검증

새 드리프트/가속/감속 동작을 순수 시뮬레이션으로 검증하고 기존 충돌/중복 생산/지름길/저장 테스트를 유지한다. 실제 Windows 플레이어에서 여섯 레시피, 실제 드리프트 부스트, 카메라/일시정지, 화면과 저장을 검증한다. 최종 파일은 Builds/DrivingFeel에 배포한다. 현재 사용자의 Builds/Windows 프로세스는 종료하지 않는다.

## 사용자 추가 지정

사용자는 빠른 속도와 강한 가속을 우선하고, 카트라이더 같은 느낌과 이니셜D 같은 느낌을 둘 다 시험해보고 싶다고 지정했다. 따라서 가게에서 두 주행 스타일을 선택한다. 두 맵/레시피/업그레이드는 공통이며 주행 도중 변경하지 않는다.

- 카트: 기본26m/s, 빠른가속, 즉각적인 조향에 짧은 입력 완충, 드리프트 해제 부스트. 약한부스트 속도상한+9/순간가속+5, 강한부스트+14/+8. 지속시간1.1/1.7초.
- 다운힐: 동일 기본최고속도, 더 느린 조향/차체반응과 관성, 감속 진입과 가속 탈출, Space/S+조향 미끄러짐, 해제부스트없음. 완료한 드리프트 횟수를 품질에 반영한다. 실제 경사진 산길 추가를 의미하지 않으며 같은 코스에서 주행감을 비교하는 모드다.
- Blender에서 자체 디자인한 작은 스포츠쿠페를 다운힐 차량으로 제작한다. 가게 주행스타일버튼과 주행중표시로 구분한다. 스타일은 이번실행중유지, 저장형식V3는그대로.
- 두 스타일에서 실제 맵완주, 서로다른입력반응, 카트부스트/다운힐드리프트 완료, 모델/카메라 전환, 저장과 납품을 검증한다. 자동 테스트는 조작감 선호도를 확정하지 않는다.
