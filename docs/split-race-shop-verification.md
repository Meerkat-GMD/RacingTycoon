# 좌우 동시 주행·판매 검증

2026-09-22 · Unity 6000.5.3f1 · Windows

기본 화면에서 왼쪽은 자동 주행과 생산, 오른쪽은 주문과 판매를 동시에 진행한다. 완주 시 결과창 없이 제품 하나와 보상을 받고 다음 생산을 이어간다. 같은 맵과 차량에서는 속도와 위치를 유지한다. 맵·맛·차량 변경은 다음 바퀴에 적용한다.

실행 검사는 실제 GameController와 uGUI 버튼으로 자동/수동 전환, 연속 두 바퀴 생산, 주행 중 판매, 중복 전달 차단, 저장, 일시정지, 다음 맛·맵 예약, 재고 포화 시 주행 유지, 판매 후 온전한 새 바퀴 생산, 모터·진열대 업그레이드를 확인한다. 검사 수에는 UI 경계·문구 넘침·준비 조건 검사가 포함된다.

자동 운전은 두 맵과 두 차량 스타일에서 기본·업그레이드 모터, 20ms·50ms 간격으로 각각 세 바퀴를 충돌 없이 완주했다. 수동 코너 주행 뒤 자동 운전 재개도 검사했다. 일시정지는 주행과 손님 대기 시간을 함께 멈춘다.

1600×900, 1280×720, 1280×960, 1920×820에서 주행·가게 카메라가 겹치지 않고, 판매 버튼이 오른쪽 영역에 있으며, 문구가 넘치지 않는 것을 확인했다. 백그라운드 Windows 플레이어의 일반 스크린샷이 검게 저장되어 테스트 코드에서 실제 카메라와 Canvas를 렌더 텍스처에 그려 캡처한다. 20개 캡처에 실제 색상 픽셀이 포함되는지 검사하고 좌우 화면을 직접 확인했다. 캡처 도구는 배포 빌드에서 제외된다.

테스트는 별도 저장 폴더를 사용한다. 기존 저장 데이터 형식은 V3이며 완성 제품과 가게 진행을 유지한다. 현재 주행 위치와 미완성 제품은 저장하지 않는다. 물리 키보드·마우스 자동화나 장시간 사용성 평가는 포함하지 않는다.

실행 파일: `Builds/SplitShop/CottonCircuit.exe`. 최종 Release 빌드는 종료 코드 0으로 완료됐으며 `build-info.json`의 Release 구성과 `Logs/split-release-build.log`의 `COTTON_RELEASE_SUCCESS 101934345`를 확인했다. 테스트와 캡처 코드는 이 배포 빌드에서 제외된다.
