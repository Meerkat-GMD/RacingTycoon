# 검증 결과 — Cotton Circuit 레이싱 개선

검증일: 2026-09-21. Windows, Unity 6000.5.3f1, Blender 5.2.2 LTS.

| 검증 | 결과 | 근거 |
|---|---|---|
| 생산·경제·게임 흐름 | 22개 통과, 실패 0 | `Tools/test-core.ps1`, `Logs/core-tests.txt` |
| 조향·드리프트·충돌·지름길·랩 | 17개 통과, 실패 0 | `Logs/driving-tests.txt` |

실행 검증 106개는 게임 동작·오류 확인 22개와 버튼 모서리의 화면 포함 여부 84개로 구성된다. 테스트용 드라이버가 실제 `GameController`의 입력값을 갱신해 조향·카메라·솜사탕·UI·저장 코드를 실행한다. 실제 게임에는 자동 조향이 없다. 물리 키보드 입력 자동화나 사람의 조작감 평가는 수행하지 않았다.

## 확인한 동작

- 정지 시 생산량 0, W 입력으로 가속, 좌우 조향으로 자유로운 위치·방향 변경.
- 주행 중 드리프트 충전, 놓을 때 부스트 1회, 제동·벽 충돌 시 부스트 취소.
- 새 전진 거리만 생산에 반영, 부스트 중 전진 부분에 생성량 25% 보너스.
- 역주행·복귀로 솜사탕이나 랩을 추가 획득하지 않음. 벽 충돌은 만든 솜사탕을 보존.
- 실제 조향으로 본선 랩 완주 및 랩 시간 표시, 세 맛의 구간을 지나며 한 제품에 색 기록.
- 지름길 진입·주행·본선 합류 시 잘못된 벽 충돌 없음. 지름길 이용 후 결승선에서 랩 갱신.
- 일시정지 시 카트 위치·시간·생산량 정지.
- 조기 완성을 두 번 호출해도 제품은 1개만 저장. 고객이 표시된 가격으로 한 번 구매.
- 모터 구매로 코인 차감·단계 상승, 재로드 시 보유금·업그레이드·재고 복원.
- 2초 프레임 지연과 5 FPS 상황에서도 60초 제작 시간 유지.
- 이전 저장 형식 유지, 손상된 저장 덮어쓰기 보호 및 명시적 초기화 시 보관.

## 화면 검토

가게·주행·부스트·지름길·결과·도움말을 실제 플레이어에서 캡처했다. 추적 카메라, 미니맵, 솜사탕 미리보기, 한글 표시, 차체 방향, 부스트 궤적, 타이어 자국, 표지판 방향과 면을 확인했다. 지름길 게이트는 진입 차량을 향하며 노면 색과 솜사탕 맛 표시가 맞는다.

검증 해상도는 1280×720, 1600×900, 1920×1080, 1280×960, 1600×1000, 1920×820이다. 주행 화면도 4:3 및 울트라와이드 비율에서 별도로 검사했다. 화면 구성은 가운데 정렬되며 버튼 잘림 및 `UI_TEXT_OVERFLOW` 경고는 없다.

대표 화면은 `docs/screenshots/`의 `race.png`, `boost.png`, `shortcut.png`, `shop.png`, `result.png`에 보관했다. 개발 플레이어 캡처에는 Development Build 표시가 있다.

## 배포와 범위

배포본은 `Builds/Windows/CottonCircuit.exe`다. 최종 `Tools/build.ps1 -Release`는 자동 테스트 코드를 제외하고 동일한 게임 코드와 씬을 빌드한다. 그래픽 및 전체 플레이 사이클 검증은 개발 플레이어에서 수행했다.

직접 조향, 드리프트 부스트, 본선과 지름길 1개, 세 맛, 판매·업그레이드를 제공한다. 상대 AI·고스트·모바일 조작은 이번 범위에 포함하지 않는다. 솜사탕은 경로 기록을 3D 솜 메시로 표현하며 실제 섬유 물리 시뮬레이션은 아니다. 장시간 경제 밸런스와 조작감은 플레이 피드백에 따라 조정할 수 있다.

최종 배포 빌드는 종료 코드 0과 `COTTON_RELEASE_SUCCESS 96646301`을 확인했다. `Builds/Windows/build-info.json`의 구성은 Release다.
