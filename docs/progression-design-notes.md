# 구현 중 기획 결정 기록

2026-09-24. 사용자가 가격·효과량·노드 배치를 위임하고 전체 구현을 승인했다. 진행을 멈추지 않고 합리적인 기본 규칙을 적용하되, 사용자 판단이 필요한 발견을 이 문서에 남긴다.

## 이번 구현에서 적용할 기본 규칙

- 여러 선행 노드가 연결되면 **모든 선행 노드를 1레벨 이상** 구매해야 한다.
- 트리 구매와 장비·레시피·알바 배치는 영업 준비 중에 한다. 영업 중에는 직접 운전할 기계와 해당 기계의 투입 설탕 등급을 변경할 수 있다. 제작 중인 제품과 다른 등급으로 변경하는 것은 추출 후 가능하다.
- 기계 전환은 영업시간을 멈추지 않는다. 각 기계의 진행 상태는 유지하며, 알바 배치 기계는 자동 생산하고 미배치 기계는 멈춘다.
- 알바는 지정 메뉴를 유지한다. 재료비가 부족하면 해당 기계만 기다리며, 돈이 생기면 재개한다. 임의로 무료 메뉴로 바꾸지 않는다.
- 기본 딸기 설탕은 계속 무료다. 유료 투입은 실제 들어간 양에 비례하여 정수 코인으로 올림한다. 투입 거절은 무료이며, 교체·비우기·마감 폐기에 환급은 없다.
- 설탕 등급과 기계 등급 중 낮은 제작 한도를 적용한다. 상한에 도달한 뒤에는 설탕을 추가 소비하지 않는다.
- 첫 상품은 크기 표시 없는 기본 딸기 제품이다. 2등급 설탕을 해금하면 소·중 구분이 나타나고, 3등급에서 대가 열린다. 기본 설탕은 소의 크기에 해당한다.
- 손님은 해금된 맛과 보유 기계·설탕 등급으로 실제 만들 수 있는 크기만 주문한다. 지역별로 주문 비율, 손님 모습과 지불액이 달라진다.
- 마감에는 재료비와 순이익을 표시하고, 이미 판매 때 받은 매출을 중복 지급하지 않는다. 다음 영업 시작 전에 모든 재고·설탕·제작 상태를 비운다.
- 1차는 3개 기계, 3가지 맛, 3등급 설탕, 4개 장사 위치로 구성한다. 상위 등급과 지역 추가로 후속 확장이 가능하도록 한다.
- NPC는 오리지널 솜사탕 가게 조력자로 제작한다. 상시 안내는 짧은 대사와 숫자·아이콘으로 제한하고, 기능 설명은 호버로 제공한다.

## 사용자 판단이 필요한 발견

현재 구현을 막는 항목은 없다. 실제 플레이 감각으로 판단해야 할 성장 시간과 난이도는 자동 시뮬레이션 가정을 함께 기록하여 후속 검토 대상으로 남긴다. 발견이 생기면 이 절에 적용한 임시 규칙과 영향 범위를 추가한다.

## 제작 중 추가로 확정한 규칙

- 알바에게 다른 맛의 제작 중 제품을 넘기면 그 제품을 원래 맛·설탕 등급의 한도 안에서 먼저 완성하고, 이후 지정 레시피로 돌아간다. 호환되지 않는 잔여 설탕을 바꿀 때는 일반 유료 투입과 같은 결제 규칙을 사용하며 환급하지 않는다.
- 진열대 제품을 이어 만들 때 현재 설탕 등급이 제품의 원래 등급보다 낮으면 받지 않는다. 높은 등급으로 가져와도 원래 제품의 크기 한도는 늘어나지 않는다. 무료 기본 설탕으로 고급 제품을 계속 키우는 우회를 막는다.
- 영업 중 기계 전환은 주행 위치·속도와 미완성 제품을 유지한다. 프로그램을 다시 켜면 재료·제품·시간은 복원하되 주행 위치는 해당 코스 출발점으로 복귀한다.
- 기존 V1–V6 저장은 돈과 영구 업그레이드를 이전하고 준비 화면에서 시작한다. 이전 영업의 소비성 재고는 초기화하며 직전 파일은 백업한다.
- 그래프는30개 노드·58단계. 실제 사람이 플레이한 성장 시간은 아직 측정하지 않았으며, 시뮬레이션은 영업 중 가능한 조작만 허용한 가정을 별도로 기록한다.
- 설탕 흔들기의 세기는 세로로 움직인 폭으로 계산한다. 기준 화면 1600×900에서 12px 이하는 무시하고, 24px는1g·60px는4g·132px 이상은10g으로 제한한다. 방향을 바꾸어야 투입되며, 작은 연속 흔들림도 매번 고정10g을 넣지 않는다. 화면 크기에 맞춰 좌표를 보정한다.
- 유료 설탕의 소량 투입에도 기존 정수 코인 올림 규칙을 유지한다. 같은 총량을 여러 번 작게 나누면 한 번에 넣을 때보다 재료비가 커질 수 있다. 소수 코인이나 누적 요금제로 바꿀지는 후속 경제 조정 항목이며, 현재는 호버로 과금 방식을 표시한다.
- 2026-09-26 정정: 흔들기 폭은 플레이어 설정이 아니라 Unity Inspector에서 개발자가 조절한다. `Cotton Circuit`의 `Game Controller`에 10g 기준 폭24~600px, 기본132px를 노출한다. 씬 직렬화 값이 기준이며 플레이 중 변경은 즉시 반영한다. 이전 게임 내 조절 UI와 별도 파일 저장 기능은 제거했고, 기존 설정 파일은 값을 덮어쓰지 않는다. 영구 반영하려면 플레이 모드 밖에서 변경 후 씬을 저장한다.
