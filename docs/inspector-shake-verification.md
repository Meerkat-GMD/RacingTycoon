# Inspector에서 설탕 흔들기 조절

2026-09-26 사용자 정정 반영. 게임 내 설정 UI와 별도 설정 파일 저장을 제거하고 Unity의 씬 직렬화 값으로 전환했다.

`Assets/CottonCircuit/Scenes/CottonCircuit.unity`를 열고 Hierarchy의 **Cotton Circuit**을 선택한다. **Game Controller → 설탕 흔들기 → 10g 흔들기 폭 (px)**에서 값을 조절한다.

- 범위24~600, 기본132. 값이 클수록 같은 동작에서 설탕이 적게 들어간다.
- 플레이 중에도 변경한 값으로 다음 흔들기부터 동작한다. 변경 전에 시작한 미완료 흔들림은 버려 갑자기 투입되지 않게 한다.
- Unity의 일반적인 플레이 모드 규칙을 따른다. 영구적으로 유지하려면 플레이를 종료한 뒤 값을 지정하고 씬을 저장한다.
- 기존 `sugar-input-settings.txt`는 사용하거나 변경하지 않는다. 영업 초기화나 새 가게 시작도 Inspector 값을 변경하지 않는다.
- 기존 씬 재생성/빌드 스크립트는 직렬화된 값을 먼저 읽어 새 컨트롤러에 넘기므로 저작한 설정을 보존한다.

검증: 핵심 흔들림23개 통과. 실제 플레이어429개 통과(`Logs/InspectorShakeSmoke`):132px 흔들기가 Inspector252에서5g, Inspector132에서10g을 투입하며, 게임 재초기화 없이 변경이 반영되는 것을 확인했다. 미완료 흔들림 초기화, 이전 설정 파일 무시, 게임 내 조절 UI 제거 및 새 가게 시작 시 값 유지도 확인했다.

Unity Editor에서는 실제 `SerializedObject` 편집, `JsonUtility` 직렬화 왕복, 기본값과 범위 및 비정상 수치 검증을 수행했다. 실제 도움말 화면에서 조절 UI가 사라졌음을 캡처로 확인했다. 독립 코드 검토에서 추가 결함 없음.

Editor 통합 검사73개 통과. 임시 씬에252를 저장한 뒤 이미 열린 씬과 저장 파일의 미리보기 씬 양쪽에서 빌드용 값 읽기가252를 보존함을 확인했다. 검사 후 임시 씬을 제거하고 원래 활성 씬으로 돌아간다. Development 및 Release 빌드 성공(종료 코드0). 실행 파일도 `Builds/Progression/CottonCircuit.exe`로 갱신했다.
