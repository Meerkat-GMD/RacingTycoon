실행 확인에는 게임 동작, 버튼 호출, 화면 범위·텍스트 넘침 검사와 테스트 준비 조건이 포함된다. 별도 저장 폴더에서 실제 GameController의 가속·조향 입력과 uGUI 버튼의 onClick을 실행한다. 물리 키보드·마우스 자동화나 사람의 조작감 평가는 수행하지 않았다. 게임에는 테스트용 자동 조향이 없다. 구형 자동 중량 완성 API는 회귀 테스트에만 유지되며 실제 게임은 한 바퀴 완주 API를 사용한다.

## 실제 게임에서 확인한 흐름

- 첫 손님 → 주문에 맞는 맵·맛 자동 설정 → 완주 → 솜사탕 보관 → 가게 복귀 → 재고 선택 → 직접 건네기 → 판매가·팁 지급.
- 1번 맵의 작은 60g과 2번 맵의 큰 120g에 각각 딸기·소다·바닐라, 총 여섯 조합을 완주했다. 제품의 모든 샘플이 설정한 맛이며 경로 변화는 두께로 남는다.
- 목표 중량이 찬 뒤에도 Racing 상태 유지. 실제 한 바퀴 이후에만 제품과 보상 지급. 반복 완료 호출은 추가 제품·코인을 만들지 않는다.
- 기본 속도 주행에서 작은 맵 46.04초, 큰 맵 65.68초, 모두 벽 충돌 0회였다. 첫 주행은 정지 검사 1초를 포함해 47.04초였다. 이 수치는 자동 시험 운전자 기록이다.
- 정지 생산 없음, 일시정지 중 주행·고객 시간 정지, 결과 중 고객 시간 정지, 제작 중 고객 시간 경과.
- 포기 첫 입력은 확인 안내, 두 번째 입력은 제품·보상 없이 중단. 제한 시간 초과도 제품을 만들지 않는다.
- 자동 판매 없음. 잘못된 재고 또는 중복 전달은 코인·재고를 변경하지 않는다.
- 진열대 6→9→12칸, 꽉 찬 재고 출발 제한, 선택 재고 두 번 확인 후 삭제. 품질과 완주 보상 및 판매·팁이 저장된다.
- V1/V2의 코인·재고·업그레이드를 V3로 보존. V2 대기 시간은 2.5배로 이전해 만족도 비율 유지. 기존 제품은 품질 0으로 기존 가격 유지. 잘못된 품질과 손상 파일은 덮어쓰기 거부.

## 코스와 에셋

| 코스 | 길이 | 순수 주행 시험 | 지름길 단축 |
|---|---|---|---|
| 1번 · 슈가웨이 | 809.83m | 46.02초 | 23.78m |
| 2번 · 클라우드런 | 1,162.51m | 65.72초 | 39.73m |

두 코스는 서로 다른 배치이며 각 코스의 본선·지름길이 실제 조향으로 연결된다. 도로 경계까지 공통 기계의 반경 200m 안에 들어간다. 선택한 코스만 표시하고 미니맵도 해당 코스로 바뀐다.

Blender 원본 `Art/Blender/MapLandmarks.blend`와 FBX 2종은 유한 좌표·양의 면적·닫힌 메시·외향 법선·재질·크기·원점·FBX 재임포트를 검사했다. 터널은 주행 공간을 여러 위치의 광선으로 확인했다. 기존 모델까지 총 17종이다. `map-landmarks-preview.png`를 직접 확인했다.

가게·두 레이싱 맵·결과·확장 진열대 화면을 확인했다. 1600×900, 1280×720, 1280×960, 1920×820에서 버튼이 화면 안에 있고 텍스트 넘침이 없음을 검사했다. 최종 화면은 `docs/screenshots/maps-*.png`에 보관한다.

## 배포

최신 실행 파일은 `Builds/MapRecipes/CottonCircuit.exe`다. 기존 실행 중인 게임을 종료하지 않고 별도 폴더로 빌드했다. 저장 경로가 같으므로 이전 게임을 닫은 뒤 최신 버전을 실행한다.

최종 배포 빌드는 종료 코드 0, COTTON_RELEASE_SUCCESS 102916121, build-info.json의 Release 구성을 확인했다. 개발 플레이어 검증 후 -Release로 자동 검증 코드를 제외한 실행 파일을 생성했다. 경쟁 AI, 모바일 조작, 직원 자동화, 가게 자유 배치는 포함하지 않는다.
