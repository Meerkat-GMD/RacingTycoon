# 검증 결과 — Cotton Circuit

검증일: 2026-09-21. 환경: Windows, Unity 6000.5.3f1, Blender 5.2.2 LTS.

## 통과한 검증

| 검증 | 결과 | 근거 |
|---|---|---|
| 핵심 생산·경제·게임 흐름 | 22개 통과, 실패 0 | `Tools/test-core.ps1`, `Logs/core-tests.txt` |
| Unity 씬·FBX·저장 | 14개 통과 | `Logs/development-build.log`, `Logs/editor-checks.txt` |
| 실제 Windows 개발 플레이어 | 74개 확인 통과 | `Logs/Smoke-release-candidate/result.txt`, `player.log` |
| Blender FBX 재임포트 | 9종 통과 | `Art/Blender/validate_assets.py`, `docs/briefs/blender-report.md` |
| 코드 리뷰 | 주요 지적 2개 수정 후 재검토 통과 | `docs/briefs/code-review.md` |

실행 검증의 74개 확인은 14개 게임 동작 및 오류 확인과, 3개 화면 비율에서 5개 버튼의 네 모서리를 검사한 60개 레이아웃 확인으로 구성된다. 자동 플레이는 실제 `GameController`와 카트·솜사탕·UI·저장 로직을 실행한다. 물리적인 키보드 키 입력을 자동화한 테스트는 아니다.

## 확인한 플레이 흐름

- 가게에서 출발, 정지 상태의 생산량 0, 실제 가속과 레인 이동.
- 딸기·소다·바닐라 샘플을 같은 제품에 기록하고 중앙 막대에 표현.
- 위치 복귀로 추가 생산이 발생하지 않음.
- 일시정지 시 시간과 생산량 정지.
- 조기 완성을 두 번 호출해도 제품이 한 번만 재고에 추가됨.
- 138g 제품 판매로 148코인 수령, 모터 구입으로 120코인 차감.
- 저장을 다시 읽어 보유금 108, 모터 1단계, 판매 후 빈 재고 복원.
- 2초짜리 느린 프레임과 300 × 0.2초의 5 FPS 상황에서 실제 경과 시간 유지.
- 잘못된 저장 파일의 덮어쓰기를 차단하고, 명시적인 새 게임 시 기존 파일 보관.

## 화면 검토

실제 플레이어 캡처를 확인했다. 가게·주행·결과·도움말의 한국어, 버튼, 모델 방향, 재질 및 솜사탕 표시를 검토했다. 주행 장면의 카트가 전방으로 보이도록 FBX 좌표 변환을 수정했고, 메시 참조가 씬 생성 중 해제되던 문제를 수정했다. 솜사탕 표면은 Blender에서 부드러운 법선으로 내보내고 겹치는 솜을 추가했다.

검증 해상도: 1280×720, 1600×900, 1920×1080, 1280×960, 1600×1000, 1920×820. 16:9 이외의 화면은 전체 게임 구성을 가운데 맞추고 여백을 둔다. 캡처에서 UI 잘림을 확인하지 않았으며 `UI_TEXT_OVERFLOW` 경고는 없다.

보관한 대표 화면:

- `docs/screenshots/shop.png`
- `docs/screenshots/race.png`
- `docs/screenshots/result.png`

대표 화면은 자동 검증용 개발 플레이어에서 캡처했으므로 Development Build 표시가 있다. 최종 Windows 배포 빌드는 자동 플레이 검증 코드를 제외한다.

## 범위와 제한

- 첫 플레이 버전: 코스 1개, 원형 주행 보조, 세 맛과 세 종류의 업그레이드.
- 경쟁 AI, 자유 조향/충돌 시뮬레이션, 가게 자유 배치, 모바일 조작은 구현 범위 밖이다.
- 솜사탕은 기록된 각도·레인·색상을 바탕으로 겹친 3D 솜 덩어리로 표현한다. 실제 섬유 물리 시뮬레이션은 아니다.
- 한국어는 Windows 시스템 글꼴에 의존한다. 다른 OS는 검증하지 않았다.
- 장시간 경제 밸런스와 사용자에 의한 조작감 평가는 이후 플레이 피드백이 필요하다.

## 배포 빌드

`Tools/build.ps1 -Release`가 종료 코드 0으로 완료되었고 `COTTON_RELEASE_SUCCESS`를 확인했다. 배포용 실행 파일은 `Builds/Windows/CottonCircuit.exe`이며, 자동 플레이 코드가 포함되지 않는다. 배포 플레이어의 별도 그래픽 없는 시작 검사에서 초기화 후 실행 상태를 확인했고 예외 로그는 없었다. 그 검사 프로세스만 종료했다. 실제 그래픽·전체 사이클 검증은 같은 게임 코드의 개발 플레이어에서 수행했다.
