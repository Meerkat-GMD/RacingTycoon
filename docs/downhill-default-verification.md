# 기본 다운힐 스타일 변경

저장 형식은 V8이다. 차량 스타일의 숫자 의미는 그대로 유지한다 (`0`: 클래식 카트, `1`: 다운힐).

- 새 진행에서는 다운힐을 즉시 사용할 수 있으며, 클래식 카트는 기존 `coupe` 특성으로 해금한다.
- V7 저장은 변경 전 조건으로 먼저 검증한다. `coupe` 없이 저장된 기본 카트만 다운힐로 바꾼다.
- `coupe`를 구매한 V7 저장은 카트/다운힐 중 선택했던 스타일을 보존한다. 특성 ID·구매 내역·가격은 이 이관으로 바뀌지 않는다.
- V7에서 해금 없이 선택한 다운힐, 부모 없이 구매한 특성, 음수 잔액 등은 이관 전에 거부한다.
- 진행 데이터 부재 표식은 유지한다. Unity가 만드는 빈 인라인 객체는 스타일 값이 0 또는 1일 때만 허용하며, 구매·선택·단계 등 의미 있는 숨겨진 데이터는 버리지 않는다.

`Tools/test-progression-save.ps1`: **19개 통과, 0개 실패**.

실제 JSON 파일을 통한 검증에는 V7 영업 중 저장을 불러와 다운힐로 전환한 뒤 V8로 재저장하는 경로가 포함된다. 잔액 997원, 남은 시간 174초, 재료비 3원, 보관 중인 제품, 제작 중인 소다 배치, 선택 기계와 모든 특성 구매를 보존하며 차량 스타일 외의 저장 상태가 같음을 확인한다. 새 다운힐 및 해금 후 선택한 카트의 저장/불러오기도 검증한다.

Unity의 실제 `JsonUtility`와 플레이어 실행 검증은 상위 작업의 빌드 및 런타임 검증 결과로 보완한다. 이 스크립트는 Mono 경계용 JSON 대체 구현을 사용한다.

## 주행 및 화면

기존 다운힐 물리와 쿠페 모델을 기본으로 사용한다. 새 게임은 별도 구매 없이 다운힐이며, 기계 관리의 차량 선택에서도 다운힐을 먼저 표시한다. 이전 `coupe` 노드는 같은 저장 ID·가격·선행 조건을 유지하면서 선택형 클래식 카트 해금을 담당한다. 차량 업그레이드는 두 스타일에 공통 적용된다.

다운힐로 전환할 때 남아 있던 카트 부스터를 즉시 제거하도록 수정했다. 현재 위치·속도·진행 거리는 바꾸지 않으므로 기계 전환 시 주행 상태를 보존한다.
