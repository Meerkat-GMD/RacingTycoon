# 솜사탕 레이싱 타이쿤 — Cotton Circuit

작성일: 2026-09-21. 사용자 선택: **막대 회전 방식 — 솜사탕 기계 안을 달리며 중앙 막대에 실을 감아 제작**. 이 선택에 따라 구현을 진행한다.

## 목표
PC 키보드로 거대한 솜사탕 기계 안에서 카트를 운전하고, 중앙 막대에 솜사탕을 감아 손님에게 판매하며 가게를 성장시키는 첫 플레이 버전. 파스텔풍 3D, 한국어 UI, Blender 제작 에셋을 사용한다.

## 플레이
- 가게에서 출발 → 60초 주행 → 제품 완성 → 가게 진열 → 손님 구매 → 업그레이드 → 다음 주행.
- 원형 기계 안의 세 동심원 레인을 달린다. 원형 주행 보조로 중앙 막대 주변을 안정적으로 돌며, W/위쪽은 가속, S/아래쪽과 Space는 제동, A/D 및 좌우는 안쪽/바깥쪽 레인 이동이다.
- 안쪽은 딸기색, 가운데는 소다색, 바깥쪽은 바닐라색 설탕이다. 선택한 레인에 따라 막대에 감기는 실의 색과 층의 두께가 달라진다.
- 이동한 각도만큼 중앙 막대에 실이 감긴다. 완주 횟수에 따라 솜사탕의 층이 쌓이며, 반지름에 따라 층의 볼륨이 달라진다. 카트와 막대를 연결하는 실로 관계를 보여준다.
- 가속과 레인 선택으로 제한 시간 동안 솜사탕을 만든다. 정지하면 생산되지 않는다. 적재량이 다 차면 조기 완성할 수 있다. Enter로 조기 완성, R로 안전한 출발 위치로 복귀한다.
- 제품의 이름, 무게, 색 조합, 예상 판매가를 결과 화면에서 확인한다. 가게에 진열한 제품은 일정 간격으로 오는 손님이 하나씩 구매한다.
- 카트 모터(속도), 설탕통(생산 상한), 가게(판매 단가) 세 업그레이드를 구입한다. 각 3단계이며 잔액 부족 시 구매할 수 없다.
- 시작 자금은 80코인, 첫 업그레이드는 120코인이다. 첫 주행과 판매를 통해 업그레이드를 구매하도록 안내한다. 판매 대기 재고가 가득 차면 판매 후 출발하도록 안내한다.

## 제작 규칙
생산 로직은 Unity와 독립적인 C#으로 분리한다. 실제 이동한 각도를 거리와 함께 기록하고, 일정 각도마다 색상·반지름·누적 회전값이 있는 샘플을 만든다. 원주를 가로지르는 순간 이동은 생산에서 제외하고, 위치 초기화 시 이전 샘플 기준을 재설정한다. 완성품과 중앙 막대 표현은 동일한 샘플을 사용한다. 솜사탕 무게와 레인 다양성, 가게 등급으로 가격을 계산한다. 빈 주행은 재고를 생성하지 않는다. 생산 상한과 재고 상한을 지킨다.

## Blender 에셋
`Art/Blender/CottonCircuit.blend`와 재생성 Python 스크립트, Unity용 FBX를 제공한다. 모델 목록: 둥근 솜사탕 카트, 중앙 제작기/막대, 차양 판매대, 솜 덩어리, 손님, 설탕 결정, 시작 아치, 장식 나무/램프. 게임은 Blender에서 제작한 모델을 실제로 사용한다. 원본과 Unity 모델의 재질 이름을 일치시키고 색상은 Unity에서 명시적으로 지정한다.

## 화면과 연출
크림색 배경, 남색 글자, 딸기 분홍·소다 청록·바닐라 노랑을 사용한다. 고정된 높은 사선 카메라로 원형 기계와 카트를 함께 보여준다. 가게에서는 진열대에 카메라가 부드럽게 이동한다. HUD는 보유금·날짜·목표, 남은 시간·속도·생산량, 조작 안내를 표시한다. 가게와 결과는 버튼을 눌러 진행한다. 버튼 상태와 이벤트 피드백, 짧은 자체 생성 효과음을 넣는다. Escape는 일시정지 및 도움말이다.

## 저장과 오류 처리
보유금, 업그레이드, 일수, 판매 대기 제품을 버전이 있는 로컬 JSON에 저장한다. 주행 중간은 저장하지 않는다. 임시 파일 작성 후 교체하고 백업을 보관한다. 손상된 파일은 덮어쓰지 않고 복구 안내를 표시하며, 별도의 새 게임 시작 시 기존 파일을 보관한다. 테스트와 자동 플레이는 별도 저장 경로를 사용한다.

## 구현 파일 경계
- `Assets/CottonCircuit/Scripts/Core/`: 회전 생산, 판매/업그레이드, 저장 데이터.
- `Assets/CottonCircuit/Scripts/`: 카트, 솜사탕 뷰, 게임 흐름, UI, 월드, 사운드, 저장 어댑터.
- `Assets/CottonCircuit/Editor/`: FBX 재질/프리팹 구성, 씬 생성, Windows 빌드, 에디터 검증.
- `Assets/CottonCircuit/Tests/Editor/` 및 `Tools/Tests/`: 경제/생산 회귀 검증 및 씬 스모크 테스트.
- `Art/Blender/`, `Assets/CottonCircuit/Models/`: 원본/임포트용 에셋.

## 완료 기준
1. 씬에서 Play를 누르거나 Windows 실행 파일을 열어 주행·제작·판매·업그레이드를 반복할 수 있다.
2. 중앙 막대에 회전에 맞춰 층이 생기고 레인 선택이 제품 색/볼륨에 반영된다.
3. 정지/위치 복귀/프레임률 변화에 의한 생산 오류가 없고 시간/적재량/재고 제한을 지킨다.
4. 이중 완료/판매/구매로 돈 또는 재고가 잘못 증가하지 않는다.
5. 재실행 후 보유금과 업그레이드, 제품이 복원된다.
6. Blender 원본과 재생성 스크립트가 있고 실제 게임에 FBX 모델이 사용된다.
7. 핵심 계산 테스트, Unity 컴파일, 시각 검토, 전체 플레이 사이클, Windows 빌드를 확인한다.
8. README에 실행 방법, 조작, 작업물 위치, 검증 결과와 알려진 제한을 기록한다.

## 확인한 환경
Unity 6000.5.3f1과 Windows 빌드 지원, Blender 5.2.2 LTS를 확인했다. 작업 폴더는 처음에 비어 있었다. 연결된 Unity MCP는 다른 프로젝트이므로 사용하지 않는다. 기존 다른 Unity 프로젝트는 수정하거나 종료하지 않는다. 이 프로젝트는 가벼운 Built-in 렌더링과 uGUI를 사용한다. 한국어는 Windows의 맑은 고딕 시스템 글꼴을 런타임에 사용하고 시스템 글꼴 파일을 재배포하지 않는다.
