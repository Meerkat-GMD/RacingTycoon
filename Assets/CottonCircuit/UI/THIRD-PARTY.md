# UI asset sources

- **Kenney UI Pack 2.0** — https://kenney.nl/assets/ui-pack — CC0. Selected PNG icons are under `Art/`; the original license is `Art/Kenney-LICENSE.txt`. Original archive and preview are retained in the project root's `Art/UI/` directory. Source archive: https://kenney.nl/media/pages/assets/ui-pack/f651646eab-1718203990/kenney_ui-pack.zip
- **Kenney Cursor Pack 1.1** — https://kenney.nl/assets/cursor-pack — CC0. `Art/HandPoint.png` and `Art/HandClosed.png` are `PNG/Outline/Double/hand_point.png` and `hand_closed.png`; the original license is `Art/Kenney-Cursor-LICENSE.txt`. Original archive is retained in the project root's `Art/UI/` directory. Source archive: https://kenney.nl/media/pages/assets/cursor-pack/461b29df18-1717599281/kenney_cursor-pack.zip (SHA-256 `baa87634f3cfd294b0c83e70222053aab2f56d19f78eca4067b9b38a555269cc`, downloaded 2026-09-28). The tutorial markers `Art/GuideArrowDown.png`, `Art/GuideArrowUp.png` and `Art/GuideArrowLeft.png` are `PNG/Red/Double/arrow_basic_s.png`, `arrow_basic_n.png` and `arrow_basic_w.png` from the UI Pack above.
- **Kenney Input Prompts 1.5** — https://kenney.nl/assets/input-prompts — CC0. `Art/KeyF.png`, `Art/MouseRight.png`, `Art/KeyW.png`, `Art/KeyA.png`, `Art/KeyS.png`, `Art/KeyD.png`, `Art/KeySpace.png`, `Art/KeyShift.png`, `Art/KeyR.png`, `Art/KeyEscape.png` and `Art/MouseLeft.png` are `Keyboard & Mouse/Default/keyboard_f_outline.png`, `mouse_right_outline.png`, `keyboard_w_outline.png`, `keyboard_a_outline.png`, `keyboard_s_outline.png`, `keyboard_d_outline.png`, `keyboard_space_icon_outline.png`, `keyboard_shift_icon_outline.png`, `keyboard_r_outline.png`, `keyboard_escape_outline.png` and `mouse_left_outline.png`; the original license is `Art/Kenney-InputPrompts-LICENSE.txt`. The license is also kept in the project root's `Art/UI/KenneyInputPrompts/`. Source archive: https://kenney.nl/media/pages/assets/input-prompts/8de120163f-1783763952/kenney_input-prompts_1.5.zip (SHA-256 `ac2fcf599080b0f3ba2d174c9474db6df1a0e96ff0662580e2da79a122ab78a1`, downloaded 2026-09-29).
- **Noto Sans KR** — https://github.com/google/fonts/tree/main/ofl/notosanskr — SIL Open Font License 1.1. Font file and complete license are under `Fonts/`. Source file: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanskr/NotoSansKR%5Bwght%5D.ttf. The bundled runtime font is a static Regular (weight 400) instance; conversion details and source hashes are in `Fonts/README.md`, and the original variable font is retained in the project root's `Art/UI/Fonts/` directory.

Existing game illustrations remain in `Assets/CottonCircuit/Sprites` and are reused by the new documents.

Project-generated artwork: `Art/CottonCandyFanStand.png` was created with the built-in image generation tool for the vendor-style rack. Source and prompt are recorded in [Art/CottonCandyFanStand.md](Art/CottonCandyFanStand.md). The 6-clip and 9-clip stands `Art/CottonCandyFanStand6.png` and `Art/CottonCandyFanStand9.png` are derived from it by `Tools/fan-stand-variants.py`. None of them is part of the Kenney pack.
