## 화면·Blender·배포

카트·다운힐·슈퍼 부스트·가게 화면을 직접 확인했다. 1600×900,1280×720,1280×960,1920×820에서 버튼 범위와 텍스트 넘침을 검사한다. 출발 안내가 차를 가리지 않도록 상단으로 옮겼다. 최종 캡처는 `docs/screenshots/feel-*.png`다.

Blender로 만든 스포츠쿠페는 50개 메시,8,896삼각형,1.552×3.100×1.050m다. 원본과 다시 임포트한 FBX의 좌표·면적·닫힌 메시·외향 법선·재질·크기·휠 회전축·앞 방향을 검증했다. 기존 에셋까지 총18종을 사용한다. 코스 주변 소품은 차가 다니는 위치와 렌더러 경계가 겹치지 않는지 Unity에서 확인했다.

두 모드는 현재 같은 평면 코스에서 조작감을 비교한다. 다운힐 전용 산길·경사 지형이나 경쟁 AI는 이번 변경에 포함되지 않는다. 주행 스타일은 이번 실행 중 유지되며 저장 형식V3는 그대로다.

배포 경로: `Builds/DrivingFeel/CottonCircuit.exe`. 현재 열려 있던 예전 `Builds/Windows/CottonCircuit.exe`는 종료하지 않았다. 저장 경로가 같으므로 이전 게임을 닫은 뒤 새 실행 파일을 사용한다. 최종 UI 조정 후 Windows 실행 검증188개가 다시 통과했으며, 차량을 가리지 않는 출발 안내 위치를 최종 캡처에서 확인했다.

최종 Release: 종료 코드0, COTTON_RELEASE_SUCCESS 101915881, build-info.json의 Release 구성을 확인했다. 자동 플레이 코드는 배포 빌드에서 제외된다.
