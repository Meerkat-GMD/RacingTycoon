# 다운힐 HUD 및 설탕 흔들기 수정

2026-09-24. 다운힐에서 성장 모드의 `BOOSTER` 문구가 다시 표시되던 경로를 수정했다. 전체 부스터 카드와 게이지를 숨기고 주행 호버·하단 조작 안내·일시정지 도움말에서도 부스터를 제외한다. 클래식 카트의 부스터 UI는 유지한다.

설탕은 흔들림을 감지할 때마다 고정10g을 넣던 방식에서 세로 스트로크의 폭에 비례하는 방식으로 바뀌었다. 방향을 12px 이상 반전했을 때 직전 스트로크를 확정하고 `(폭 - 12) / 12`g을 투입한다. 최대10g이며, 12px 이하의 떨림·수평 이동·최초 단방향 이동은 투입하지 않는다. 드래그 종료·취소·주행 영역 이탈은 미완료 스트로크를 초기화한다.

기준 화면 1600×900에서 24px는1g, 60px는4g, 132px는10g이다. 기존 Canvas 좌표 변환을 사용하므로 같은 상대적 화면 이동은 해상도에 관계없이 같은 양을 넣는다. 실제 수용량만큼 재료비를 계산하며 기본 딸기는 무료다. 알바의 자동 투입량과 주행 거리에 따른 솜사탕 성장 규칙은 유지한다. 저장 형식 V8은 그대로다.
