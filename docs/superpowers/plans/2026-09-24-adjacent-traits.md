# 인접한 특성 그래프 재배치 계획

사용자의 PoE 참고 이미지 피드백: 직접적인 선행 조건과 다음 특성을 가까이 붙이고 긴 교차 연결을 없앤다. 이전에 위임받은 배치 결정 권한으로 진행한다.

- 현재 분류별 격자 대신 실제 선행 관계의 연결 성분을 기준으로 위치를 정한다. 노드 ID, 가격, 효과, 단계, 선행 조건과 저장 내용은 그대로 유지한다.
- 직접 연결된 노드 사이 거리를 짧게 유지하고, 선이 다른 노드나 글자를 통과하지 않는지 수치와 렌더 이미지로 확인한다.
- 원형 노드를 작게 만들고 이름과 단계만 짧게 표시한다. 가격·효과·필요한 선행 특성은 기존 호버에 모은다.
- 전체 보기와 확대/축소를 제공하여 큰 경로를 파악한 뒤 필요한 가지를 살펴볼 수 있게 한다. 호버한 노드에 연결된 길을 강조한다.
- 기존 실제 플레이어 검증에서 구매·호버·화면 크기를 확인하고, 수정한 성장 지도를 렌더링한 뒤 Windows 빌드를 갱신한다.

담당: 좌표 최적화는 adjacent_graph_layout, uGUI 구성/연결선/실제 렌더 검증은 root. 코드 가격·성장 규칙 변경 없음.

완료: 30개 노드/36개 선행 관계 재배치, 110~188 UI 단위 인접 거리, 교차 53→4. 확대/축소·드래그·전체 보기·호버 강조 구현. 성장 규칙 14개, Editor 58개, 실제 플레이어 103개 검사 통과. 두 해상도 독립 화면 검토 및 Release 실행 파일 갱신 완료. 상세 기록은 `docs/graph-layout-metrics.md`.
